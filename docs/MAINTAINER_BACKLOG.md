# 维护清单

## P0：首个可用版本

- 使用当前官方 Python MCP SDK 实现 stdio server。
- 实现 URL 规范化、重定向展开和作品 ID 提取。
- 实现 Playwright 网络监听 resolver；支持独立启动浏览器与 CDP 附着。
- 实现视频候选识别和质量选择；音频候选尽力识别但不阻断视频下载。
- 实现异步下载、有限重试、原子落盘和 FFmpeg stream-copy 封装；支持 `audio_video` 与 `video_only`。
- 实现 FFprobe、三点解码和 SHA-256 验收。
- 输出脱敏 JSON manifest。
- 为 URL 解析、候选选择、脱敏和错误映射编写单元测试。
- 使用用户提供的测试链接做一次本机端到端回归，但不得把视频或临时 URL 提交到 Git。

## P1：稳定性

- 持久化浏览器 profile，Cookie 由用户选择是否启用。
- 下载队列与有界并发；默认解析并发 2、媒体下载并发 4，可配置。
- 中断恢复、临时文件清理和签名过期后自动重新解析。
- 结构变化探测与诊断包；诊断包默认脱敏。
- Windows/macOS/Linux CI；FFmpeg 缺失时给出清晰提示。

## P2：扩展

- 适配器接口，为其他公开短视频平台预留实现空间。
- 只下载音频、只取元数据、定时抽帧等可选工具。
- 与视频分析流水线对接，但保持本项目不依赖 ComfyUI、Whisper 或 LLM。

## 发布门槛

- 不宣称绕过平台限制。
- 不捆绑用户 Cookie。
- 不提交真实下载内容。
- 所有错误输出通过敏感信息测试。
- 至少完成一条 20 分钟以上作品和一条短视频的真实回归；分别记录是否取得音轨，不把 `video_only` 写成完整音视频。
