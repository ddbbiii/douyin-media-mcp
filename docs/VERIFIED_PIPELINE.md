# 已验证解析流程

## 验证日期与环境

- 日期：2026-07-19（Asia/Shanghai）
- 平台：Windows 11
- 浏览器：Codex 内置浏览器会话（完整音视频基线）与独立 Playwright resolver（MCP 实现）
- 后处理：FFmpeg 8.1.2 / FFprobe 8.1.2
- 测试对象：用户明确提供的公开抖音分享链接

## 真实验证结果

1. 分享短链接可以跟随重定向解析到 `https://www.douyin.com/video/<aweme_id>`。
2. 对作品页直接发普通 HTTP 请求并不稳定；一次测试最终返回 404。
3. F2 在没有可用 Cookie 的情况下调用详情接口，连续重试仍得到空响应，未能下载。
4. 同一链接在真实浏览器页面中可以正常播放，无登录墙或验证码。
5. 页面播放器使用 `blob:` URL；复制 `video.currentSrc` 不能得到可下载源。
6. 页面资源/网络请求中存在独立的 MP4 视频流与 AAC 音频流，两者 URL 带短期签名。
7. 携带浏览器 User-Agent 与作品页 Referer，可在浏览器退到后台后并行下载两条流。
8. FFmpeg 使用 `-c copy` 无损封装成功。
9. FFprobe 验收得到：H.264、1920×1080、30 fps；AAC、44.1 kHz、双声道；总时长 1309.675 秒。

上述完整音视频结果来自已验证的浏览器辅助基线。独立 MCP 的 Playwright resolver 已能稳定捕获该样本的视频流，但独立音频响应并非每次出现。根据 2026-07-19 的产品决定，音频捕获改为尽力而为：有音频时无损合并，没有音频时保存通过时长、解码和哈希验收的无声视频，并返回 `media_mode=video_only`。

## 独立 MCP 真实回归

2026-07-19 使用环境变量注入授权测试链接和项目外输出目录，执行 `pytest -m e2e`：

- 解析器：`playwright`
- 实际媒体模式：`video_only`
- 视频：H.264、1280×720、30 fps
- 时长：1309.633 秒
- 文件大小：94,345,488 bytes
- 头部、中部、尾部解码检查：全部通过
- Manifest：已生成，未包含 Cookie、授权头或临时签名媒体 URL

测试最初因断言写死 1920×1080 而失败，但媒体下载和验收已经完成。页面当次只提供了可识别的 720p 候选，因此回归标准改为验证实际返回的可用清晰度，不把请求的 `1080p` 误解为平台保证。

## 必须保留的实现细节

### 解析

- 先展开分享短链接，提取 `aweme_id`，但不要把页面 HTTP 404 直接当成作品不存在。
- 首选轻量直连解析器；遇到空响应、风控或页面动态加载时，自动切换浏览器适配器。
- 浏览器适配器监听网络响应，而不是依赖脆弱的 DOM class 名或播放器 `blob:` 地址。
- 视频候选至少依据 MIME、URL 查询参数、内容类型和媒体探测综合判断。
- 同一个作品可能有多档清晰度；需要显式质量选择策略，并记录最终选择理由。

### 下载

- 签名媒体地址取得后立即下载，因为它会过期。
- 下载请求复用页面 User-Agent、Referer；Cookie 仅在服务器明确要求时临时注入。
- 视频流与音频流允许并发下载；多个作品采用有界队列。
- 支持续传、超时、有限重试和原子重命名，避免半成品冒充成功文件。

### 合并与验收

- 默认先尝试 stream copy，不无谓重编码。
- 必须确认至少一个视频流；音频流为可选。有音频时必须一并验收，无音频时结果必须明确标记为 `video_only`。
- 对比解析阶段页面时长与成品时长，误差超阈值则失败。
- 至少抽取头部、中部和尾部的短片段做解码测试。
- 计算 SHA-256，写出 manifest；manifest 必须清除 Cookie、授权头和临时签名 URL。

## 已知边界

- 页面结构、接口和签名方式会变化，必须把抖音逻辑封装成独立 adapter。
- 无头浏览器可能比有界面浏览器更容易触发风控，应支持持久化浏览器配置和 CDP 附着模式。
- 登录、验证码和访问受限内容不能自动绕过；应返回明确的 `AUTH_REQUIRED` 或 `HUMAN_ACTION_REQUIRED`。
- 一次成功不能证明任意链接长期可用；发布前需要短视频、长视频、无登录、需登录和音视频分离等回归矩阵。音频捕获失败不再阻断视频下载，但不能伪装成完整音视频结果。

## 不得持久化的敏感数据

- Cookie、localStorage、sessionStorage
- 临时签名媒体 URL
- 完整 Authorization/Referer 查询令牌
- 用户浏览器配置目录副本
- 未经授权下载的视频样本
